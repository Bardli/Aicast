    *   Stops the service after the test.
4.  **Analyze Test Output:** The output from running `pytest` will provide the necessary stack traces and error messages to diagnose why the LLM Orchestration Service is failing to start or process requests.
5.  **Address the Root Cause:** Fix the identified issues based on the test output.
6.  **Verify Functionality:** Once the service is stable, expand the tests to cover its core functionalities (Synthesizer, Weaver, main backend updates).
